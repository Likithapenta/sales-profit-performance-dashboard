# Sales & Profit Performance Dashboard

## Project Overview
This project presents an interactive Sales & Profit Performance Dashboard created using Tableau. The dashboard helps analyze sales, profit, orders, quantity, categories, sub-categories and regional performance.

## Objectives
- Analyze sales and profit performance.
- Compare sales across regions and categories.
- Identify profitable and less profitable sub-categories.
- Understand sales trends over time.
- Calculate and analyze profit margin.
- Create an interactive Tableau dashboard.

## Tools Used
- Tableau
- Microsoft Excel

## Key Visualizations
- Sales Trend over Time
- Sales by Region
- Sales by Category
- Profit by Sub-Category
- Dual-Axis Sales & Profit Chart
- Profit Heat Map
- Profit Margin by Category
- Running Sales Total
- KPI Cards

## Calculations Used

### Profit Margin
`SUM([Profit]) / SUM([Sales])`

### Running Sales Total
A Running Total table calculation was applied to Sales to show cumulative sales over time.

## Dashboard Features
- Interactive Region filter
- Interactive Category filter
- Dashboard filter actions
- KPI cards
- Advanced visualizations
- Sales and profitability analysis

## Files Included
- `sales and profit performance dashboard.twb` – Tableau workbook
- `Sales_Profit_Performance_Dashboard.pdf` – Dashboard output

## Conclusion
The dashboard provides an interactive way to explore sales and profitability performance and helps users understand trends across different regions, categories and sub-categories.
